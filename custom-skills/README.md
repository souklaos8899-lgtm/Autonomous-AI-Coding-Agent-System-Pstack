# โฟลเดอร์สำหรับเก็บสกิลส่วนตัว (Custom Skills)

หากคุณต้องการสร้างสกิลเฉพาะทางเพิ่มเติมของตัวเอง (โดยไม่ไปปนกับโค้ดต้นฉบับของ `pstack`) สามารถสร้างโฟลเดอร์ย่อยที่นี่ได้เลยครับ

## โครงสร้างการสร้างสกิลใหม่

```text
custom-skills/
└── my-custom-skill/
    └── SKILL.md
```

## ตัวอย่างเนื้อหาใน `SKILL.md`

```markdown
---
name: my-custom-skill
description: อธิบายว่าสกิลนี้ทำอะไร และเมื่อไหร่ที่ AI ควรหยิบสกิลนี้มาใช้เองอัตโนมัติ
---

# ขั้นตอนการทำงานของสกิล

1. ตรวจสอบไฟล์ ...
2. รันคำสั่ง ...
3. ยืนยันผลลัพธ์ ...
```

หลังจากสร้างสกิลเสร็จแล้ว ให้รันคำสั่ง:
```powershell
.\pstack-ctl.ps1 sync
```
สคริปต์จะเชื่อมสกิลของคุณเข้ากับ **Antigravity**, **Cursor**, **Claude Code**, และ **Codex** ให้โดยอัตโนมัติครับ
